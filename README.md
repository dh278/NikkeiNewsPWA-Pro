# 日経営業レーダー Ver.5

日経新聞のPDF紙面をアップロードすると、Gemini AIが1面から最終面まで全記事を
自動認識し、見出し・300字要約・過去の関連動向を一括生成する営業支援PWAです。

## できること

- PDFの全ページを画像化し、Gemini APIに直接読み込ませて記事を自動認識
- 記事ごとに「見出し」「300字程度の要約」「過去の関連動向(関連する過去のニュースの解説)」を自動生成
- 人事異動・マーケットの数表は要約せず、本文をそのまま表示
- 記事の要約をタップすると、元のPDFページ画像をその場で表示(複数ページにまたがる記事は次ページも表示)
- 日付ごとに記事を絞り込み・ジャンプ
- お気に入り登録、キーワード検索
- 記事データ(見出し・要約・過去の関連動向)をGitHubリポジトリに自動バックアップ
  - Safariの「7日間未訪問でブラウザ内データが消える」仕様に影響されない
  - 元PDFページの画像も圧縮してGitHubに保存(1ページ1ファイル、重複排除)
  - 画像は90日経過で自動削除(記事テキストは残る)
  - リポジトリが800MBに近づいたら新しいリポジトリを自動作成して引き継ぐ
  - 他の端末からは、GitHubのユーザー名とリポジトリ名だけ設定すればトークン無しで閲覧可能

## ファイル構成

```
index.html          画面のHTML本体
style.css            見た目(スタイルシート)
manifest.json        PWA設定(ホーム画面追加用)
app.js                画面の動作・状態管理・GitHub連携の呼び出し
pdf-processor.js     PDFの各ページを画像化する(pdf.js使用)
gemini-extract.js    画像をGemini APIに渡し、記事認識+要約+過去動向を生成
github-store.js      GitHubへのデータ・画像保存/読込/容量管理
db.js                 端末内(IndexedDB)への記事・画像の保存
```

## セットアップ手順

### 1. GitHub Pagesとして公開する

1. GitHubでリポジトリを作成する(Publicにしておくと、他端末からトークン無しで閲覧できて便利です)
2. このZIP内の8ファイルをすべてリポジトリのルート直下にアップロードする
3. リポジトリの Settings → Pages で、公開設定を有効にする
4. `https://(あなたのユーザー名).github.io/(リポジトリ名)/` で開けるようになります

### 2. Google Gemini APIキーを取得する

1. [Google AI Studio](https://aistudio.google.com/apikey) にアクセスし、無料のAPIキーを発行する
2. アプリの「設定」画面の「Google Gemini API キー」欄に貼り付けて保存する

### 3. GitHub Personal Access Token(PDFを取り込む端末のみ)

PDFを取り込んで記事を生成・保存する端末には、書き込み権限のあるトークンが必要です。

1. [GitHubのトークン発行画面](https://github.com/settings/tokens) を開く
2. 「Tokens (classic)」タブ →「Generate new token」→「Generate new token (classic)」
3. Note(名前)を適当に入力し、スコープで「**repo**」にチェック
4. 「Generate token」を押し、表示された`ghp_...`から始まる文字列を**その場でコピー**
   (この画面を離れると二度と表示されません。忘れた場合は同じ手順で再発行してください)
5. アプリの「設定」画面で、以下3つを入力して保存する
   - GitHub Personal Access Token: 上記でコピーした文字列
   - GitHubユーザー名: 例) `dh278`
   - リポジトリ名(現在使用中): 例) `NikkeiNewsPWA-Pro`
6. 「GitHub接続テスト」ボタンで、正しく接続できるか確認する

### 4. 閲覧だけしたい他の端末の設定

書き込み(PDF取込)をしない、閲覧専用の端末では、トークンは不要です。

1. アプリの「設定」画面を開く
2. GitHubユーザー名・リポジトリ名の2つだけ入力して保存する
   (トークン欄は空のままでOK)

## 使い方

1. 「PDF取込」で日経新聞のPDFファイルを選択する
   - ファイル名が `260804新聞.pdf` のように数字6桁を含む場合、そこから日付を自動認識します
   - 認識できない場合は今日の日付として扱われます
2. しばらく待つと(ページ数に応じて数分〜)、記事の抽出・要約が完了します
3. 記事一覧の見出し下の要約をタップすると、元のPDFページ画像がその場で開きます
4. 「検索・日付ジャンプ」の日付プルダウンで、見たい日の紙面に絞り込めます
5. 起動時は自動的に最新の日付の記事が表示されます

## 注意点・運用上のヒント

- **設定値(Gemini APIキー・GitHubトークン)はブラウザのlocalStorageに保存されます。**
  Safariで「履歴とWebサイトデータを消去」をすると、これらも消えてしまいます。
  念のため、キーやトークンは別途メモアプリなどに控えておくことをおすすめします。
- コードを更新する際は、`index.html`内の`<script src="....js?v=N">`の**バージョン番号を
  必ず1つ上げてください**。上げないと、Safari等のキャッシュにより古いコードが
  読み込まれ続けることがあります。
- GitHubリポジトリはPublicを前提にしています。Privateにする場合、閲覧専用端末でも
  トークンが必要になります(その場合は読み取り専用のfine-grainedトークンを推奨)。

## 開発の背景(トラブルシューティングの記録)

開発中に発生した主な問題と原因は以下の通りです。今後同様の症状が出た場合の参考にしてください。

- **PDF内の日本語が読み取れない/画像が真っ白**:
  PDFの日本語CIDフォントを正しく描画するには、PDF.jsの`cMapUrl`指定が必須でした。
  (`pdf-processor.js`で既に対応済み)
- **`Can't find variable: X` のようなエラー**:
  必要なJSファイルがリポジトリにアップロードされていない、または読み込み順が
  誤っていることが原因でした。
- **コードを直したのに反映されない**:
  ブラウザのキャッシュが原因。`?v=N`のバージョン番号を上げることで解決します。
- **GitHub保存が動かない/401エラー**:
  トークンの入力ミス・期限切れが主な原因でした。「GitHub接続テスト」ボタンで
  即座に確認できます。
- **「Type error」という分かりにくいエラー**:
  Safari特有の、CORS関連の通信失敗を表す汎用エラーメッセージでした。
  APIリクエストのヘッダーを必要最小限に絞ることで解消しました。
